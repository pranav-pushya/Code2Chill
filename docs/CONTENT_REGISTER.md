# Code2Chill Content Register

This register tracks source evidence, publication readiness, and missing material for [Phase 1](../WEBSITE_ROADMAP.md#phase-1--establish-content-and-scope). A check date records when the cited source or the available project records were reviewed. For a missing item, the owner column identifies the person or team that can supply it.

| Status | Meaning |
| --- | --- |
| Owner-confirmed | The project owner confirmed the specific fact. |
| Source-confirmed | The cited club or organizer source supports the specific fact. |
| In repository | The supplied file exists and is available for project design work. |
| Unverified | A lead or draft needs supporting evidence before publication. |
| Missing | The value or asset is unknown and needs to be supplied. |

Use owner-confirmed and source-confirmed facts for public copy within the limits of their evidence. Record permission and credits before publishing third-party media. Update each row with a source or owner whenever a value changes.
